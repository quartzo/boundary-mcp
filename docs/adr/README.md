## Conventions

- One decision per file, numbered sequentially.
- Records are immutable once accepted; supersede a decision with a new ADR instead of rewriting it.
- Link accepted ADRs from the architecture document.
- Use `Proposed`, `Accepted`, `Rejected` or `Superseded` as the status.
